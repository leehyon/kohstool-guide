## TL;DR
可安装的 GitHub 技能库，包含 1,569+ 个可复用的 SKILL.md 指南，支持 Claude Code、Cursor、Codex CLI、Gemini CLI 等多种 AI 编码助手，通过 npx 快速安装使用

## 应用场景
- 为 Claude Code 安装可复用的操作技能以提高 AI 编码助手的工作质量
- 在 Cursor 中激活领域专用的技能插件用于 Web 开发、安全、数据等任务
- 使用预定义的 bundles 和工作流执行规划、编码、测试、安全审查等流程
- 通过 npx 一键安装并自动配置到工具对应的 skills 目录中
- 浏览 hosted catalog 搜索并比较 1,500+ 个技能以选择最适合的插件

## 用户痛点
- AI 编码助手缺乏结构化、可复用的操作指令，每次需手动编写 prompt
- 收集零散的 prompt 片段效率低，难以管理和版本控制
- 不同 AI 工具（Claude Code、Cursor 等）的技能安装路径和格式不统一
- 没有可搜索、可安装的技能目录，难以发现和选择合适的高质量技能

## 设计理念
- 可安装性优先，而非仅提供灵感
- 聚焦代理工作流，覆盖主流 AI 编码工具
- 领域专用插件实现开箱即用的最小化启动
- 支持 bundles、workflows 和插件三种抽象层次
