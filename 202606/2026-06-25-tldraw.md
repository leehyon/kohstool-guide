## TL;DR
一个基于 React 的无限画布 SDK，提供绘图、图表、多人协作等功能，可高度扩展并用于构建自定义画布应用

## 应用场景
- 在 React 应用中快速集成无限画布白板功能
- 构建支持多人实时协作的在线绘图工具
- 开发自定义形状和图表的可视化编辑器
- 创建 AI 代理可读写操作的交互式画布
- 搭建拖拽式节点编辑器或工作流自动化界面
- 为笔记或文档应用提供画布标注和草图功能
- 嵌入 Figma、YouTube 等第三方网站到画布中展示

## 用户痛点
- 从零开发一个高性能的无限画布引擎非常耗时且复杂
- 现有白板应用难以嵌入到自己的 Web 应用中定制
- 缺乏一个易用又强大的 React 原生画布组件来快速实现绘图和协作需求
- 需要实时多人同步但不想自己搭建 WebSocket 服务器
- 想扩展绘图工具但受限于固定形状和功能
- 无法在画布内自由嵌入网页或视频等富媒体内容

## 设计理念
- 无限画布
- 可扩展性
- 多人实时协作
- 基于 React 组件化
