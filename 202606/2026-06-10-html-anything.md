## TL;DR
由本地 AI 代理驱动的 HTML 编辑器，将 Markdown 瞬间转换为发布就绪的 HTML，支持一键导出到微信、X 等平台，无需 API 密钥

## 应用场景
- 快速创建杂志风格的在线文章和文档
- 生成专业级幻灯片演示文稿
- 为社交媒体（X、小红书、微信等）制作分享卡片
- 快速原型化网站页面（登录页、定价页等）
- 将数据报告转换为可视化 HTML 页面
- 生成视频制作所需的关键帧和动效帧
- 制作简历、邮件营销模板等文档

## 用户痛点
- 手动编写 HTML/CSS 耗时且需要专业技能
- Markdown 在微信、知乎等平台渲染效果差，需额外格式化
- 从内容到发布需要多步转换和设计调整
- 设计师和作家不愿直接处理样式代码
- 传统 HTML 编辑器缺乏对主流社交平台的一键导出支持

## 设计理念
- 本地优先
- 零 API 密钥配置
- Agent 驱动自动化生成
- 一次生成即可发布无需二次修改
