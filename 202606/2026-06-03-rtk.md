## TL;DR
高性能 CLI 代理，将常见开发命令输出压缩 60-90%，大幅降低 LLM 令牌消耗，单一 Rust 二进制文件零依赖

## 应用场景
- 与 Claude Code、Gemini CLI 等 AI 编程工具配合，自动压缩命令输出
- 自动重写 bash 命令（git status、ls、cat 等）以减少令牌消耗
- 测试运行器（jest、cargo test、pytest）输出精简，仅保留失败信息
- 构建与 lint 工具（TypeScript、ESLint、clippy）输出优化
- Git 操作过程中的令牌节省（status、diff、log、push）
- 文件读取与目录列表的智能压缩
- AWS CLI、Docker、Kubernetes 等云原生命令输出精简

## 用户痛点
- LLM 上下文窗口被冗长的命令输出填满，导致效率低下和 API 费用高昂
- 开发者需要手动精简输出或将长输出粘贴到 AI 工具中，耗时费力
- AI 编程工具在处理大型项目时令牌迅速耗尽，频繁断掉上下文
- 测试失败时大量冗余错误信息掩盖关键原因，难以快速定位
- 重复或无关信息（注释、空白行、进度条）占用宝贵令牌空间

## 设计理念
- 智能过滤：去除噪声（注释、空白、样板代码）
- 分组聚合：按目录、类型等汇总相似条目
- 截断与去重：保留关键上下文，消除冗余
- 透明代理：通过 Hook 自动重写 Bash 命令，零入侵集成
