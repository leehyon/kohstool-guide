## TL;DR
Claude Code 的终极资源集合，提供 176+ 插件、135 个代理、42 个命令、20 个钩子、15 条规则等，一站式发现与集成社区贡献的最佳 AI 编码工具

## 应用场景
- 快速发现并安装 Claude Code 插件
- 学习 Claude Code 钩子和技能的使用
- 管理 Claude Code 的配置和规则
- 自动化开发工作流和代码审查
- 探索 Claude Code 生态系统和配套应用
- 搭建多代理系统架构

## 用户痛点
- 缺乏 Claude Code 插件和工具的集中目录，查找困难
- 不同插件的配置复杂，整合成本高
- 社区分散，难以发现高质量的资源
- 手动管理多个配置文件和钩子脚本繁琐易错

## 设计理念
- 一站式资源集合
- 社区驱动持续更新
- 模块化可插拔
- 生产级实战验证
