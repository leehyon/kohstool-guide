- Categories: Developer Tools
- Platform: Mac, Windows, Linux

## TL;DR
统一管理 AI 编程工具的工作流，提供供应商配置、本地路由与自动故障转移，支持用量追踪、MCP 与会话管理，开源免费基于 MIT 协议

## 应用场景
- 管理多个 AI 编程工具（如 Claude Code、Gemini CLI）的供应商配置与 API Key
- 自动故障转移，当主 Provider 异常时无缝切换备用 Provider
- 实时追踪请求、Token、缓存命中、成本与订阅额度
- 可视化配置 MCP、Skills、Prompts 与跨应用会话恢复
- 团队内部共享配置预设，提升协作效率
- 录制 AI 编程教程时快速切换不同 Provider 进行演示
- 本地化存储所有配置与 API Key，保障数据安全

## 用户痛点
- 手动编辑多个 AI 工具的 JSON 配置文件，繁琐易错
- API 限流导致开发中断，需要手动切换供应商
- 无法直观了解各 Provider 的用量与费用，难以成本控制
- 切换不同 AI 工具时需要重复配置环境变量与路由
- 缺乏统一的界面管理 MCP、Skills 和会话，效率低下

## 设计理念
- 本地存储优先，数据安全可靠
- 自动故障转移与健康监控
- 零配置开箱即用
- 可视化配置与用量追踪
