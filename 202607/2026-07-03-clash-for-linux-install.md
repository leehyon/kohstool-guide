## TL;DR
在 Linux 上一键部署和管理基于 clash/mihomo 的代理环境，支持订阅管理、TUN 模式及内核升级

## 应用场景
- 为 Linux 服务器或桌面快速配置代理环境
- 管理代理服务的启动、停止和状态监控
- 管理多个代理订阅源并实现一键切换
- 启用 TUN 模式以接管全局流量
- 实时查看代理日志并追踪连接状态
- 通过 Web 面板可视化操作和管理
- 自动化更新订阅配置以保持节点可用性

## 用户痛点
- Linux 上配置 clash 代理过程繁琐且易出错
- 手动管理多个订阅源和切换节点耗时
- 缺乏统一的命令行管理工具来启停服务
- 新手难以理解复杂的配置文件格式
- 在不同 init 系统上部署时需要额外适配
