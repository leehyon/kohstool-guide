## TL;DR
一个用于控制自托管 Hermes AI agent 的原生 iPhone 客户端，支持聊天、文件浏览、任务管理等核心功能，强调隐私和免费

## 应用场景
- 在 iPhone 上与自托管的 AI agent 进行实时对话
- 管理 AI agent 的会话历史并离线浏览缓存的会话
- 浏览和搜索 agent 已安装的技能列表
- 查看和编辑 agent 的定时 cron 任务
- 通过文件浏览器探索服务器文件系统
- 切换不同的模型、配置和项目组织会话
- 监控 agent 的内存内容和使用分析

## 用户痛点
- 没有原生移动客户端，只能通过 web 界面控制自托管 AI agent
- 在手机端控制 AI agent 时缺乏流畅的原生体验
- 担心数据通过第三方中继，隐私无法保障
- 无法在移动端方便地管理会话、任务和文件
- 自托管方案的连接配置复杂，缺乏安全连接指导

## 设计理念
- 自托管控制，数据不出机器
- 隐私优先，无分析无追踪无第三方中继
- 原生 SwiftUI 体验，适配 iOS 18+
- 免费无订阅，无内购
