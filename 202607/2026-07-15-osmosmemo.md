## TL;DR
将 GitHub 仓库变成书签管理器，通过浏览器扩展快速抓取页面标题和 URL 为 Markdown 片段，一键保存到 README.md，支持标签和即时搜索

## 应用场景
- 快速捕获网页书签并保存到 GitHub
- 整理和归类个人阅读列表
- 与团队共享书签集合
- 跨设备同步和管理书签
- 基于标签分类和过滤已保存的链接
- 利用浏览器原生查找功能即时搜索书签

## 用户痛点
- 传统书签管理无法跨设备同步，数据分散
- 书签组织混乱，检索效率低下
- 书签数据封闭，难以导出或迁移
- 书签冗余和重复难以清理
- 分享书签需要手动复制粘贴，过程繁琐

## 设计理念
- 捕获速度优先
- 检索速度优先
- 一键保存到 Markdown
- 利用 GitHub 作为开放存储后端
- 键盘快捷键操作
