## TL;DR
一个运行在终端中的 Agent 多路复用器，支持持久会话、远程 SSH 附加和实时状态查看，兼容任何编码 Agent，并能从手机操控

## 应用场景
- 在远程服务器上同时运行多个编码 Agent，关闭笔记本后仍保持运行
- 从手机 SSH 连接查看 Agent 状态并重新附加到会话
- 在本地开发时保持 Agent 在后台运行，随时切换终端
- 通过插件扩展终端视图，如查看 diff、批准操作
- 在团队中共享同一终端会话进行协作调试
- 使用 CLI 和 JSON Socket API 编程控制 Agent 工作流

## 用户痛点
- 桌面 Agent 管理器无法离开本地 GUI 机器，限制远程使用
- tmux 和 Zellij 不理解 Agent 状态，无法直观查看进度
- 管理多个 Agent 需要在多个终端窗口间频繁切换
- 远程附加 Agent 会话配置复杂，缺乏统一入口
- 无法从手机等移动设备监控 Agent 运行情况

## 设计理念
- Agent 感知状态
- 持久 PTY 会话
- 终端优先界面
- 远程 SSH 附加
- 插件可扩展性
- 轻量二进制
