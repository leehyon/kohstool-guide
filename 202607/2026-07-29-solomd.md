- Added: 2026-07-29 07:44:35

- Categories: Knowledge Management, Text Input & Writing, Developer Tools
- Platform: Mac, Windows, Linux, iOS, Android

## TL;DR
免费开源跨平台 Markdown 编辑器，支持 WYSIWYG 预览、AI 重写、本地语义搜索、AutoGit 版本历史、MCP 服务器，无账户无订阅无遥测，纯文本文件永远可访问

## 应用场景
- 写长篇文章或书籍，使用专注模式和打字机模式
- 研究者管理笔记，通过语义搜索和 Wiki 链接快速定位段落
- 开发者将笔记作为 MCP 服务器集成到 AI 工具中
- 跨设备同步笔记（iCloud、Dropbox、OneDrive、Git 同步）
- 移动端快速记录和编辑 Markdown 文件
- 团队协作通过 GitHub 私有仓库进行版本控制
- 离线环境下的本地化笔记与知识管理

## 用户痛点
- 需要付费或订阅才能使用完整功能的 Markdown 编辑器（如 Typora、Obsidian）
- 现有编辑器安装包体积过大，占用磁盘空间
- 缺少本地语义搜索功能，只能靠关键词匹配
- 无法将笔记与 AI 工具（如 Claude Desktop）直接集成
- 担心数据隐私和遥测收集，希望无账户无云端绑定
- 希望自动版本历史而不需要手动配置 Git

## 设计理念
- 本地优先，离线可用，无云锁定
- 纯文本 .md 文件，始终可被其他编辑器打开的格式自由
- 开源 MIT 许可证，完全可审计
- 零默认遥测，无账户无订阅
