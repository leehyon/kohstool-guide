## TL;DR
轻量级、自包含的 Linux 服务器监控工具，零依赖，单二进制部署，通过 Web UI 和 TUI 实时展示系统指标

## 应用场景
- 实时监控服务器 CPU、内存、磁盘、网络等系统资源
- 快速部署在无外网环境的服务器上进行本地监控
- 通过 Web 仪表盘远程查看多台 Linux 主机的运行状态
- 结合 Prometheus 将监控数据纳入已有观测体系
- 使用 AI 助手分析图表数据并辅助排查问题
- 在终端中通过 TUI 界面快速浏览系统负载
- 监控 Docker、Podman 等容器运行状态和资源占用

## 用户痛点
- 传统监控工具依赖外部数据库和复杂依赖，部署繁琐
- 云监控服务需要联网和注册，不适合内网或隐私敏感环境
- 监控工具资源占用高，在小服务器或嵌入式设备上难以运行
- 无法快速获得历史数据的降采样视图，调试问题不便
- 缺少集成 AI 的轻量级监控方案，分析耗时

## 设计理念
- 单二进制零依赖
- 自包含存储引擎（环形缓冲）
- 实时流式 WebSocket 推送
- 隐私优先：无云连接、无第三方 API
