## TL;DR
类似 TextEdit 但专注于 Markdown 的免费开源编辑器 原生轻量快速 仅 4 MB 可流畅编辑千万行文件 隐私友好

## 应用场景
- 编写和编辑 Markdown 格式的文档
- 快速记录笔记和想法
- 撰写博客文章或技术文档
- 编辑 README 文件
- 作为简洁的 Markdown 预览工具
- 配合 Shortcuts 和 AppleScript 自动化工作流

## 用户痛点
- 现有 Markdown 编辑器体积大、启动慢
- 缺乏原生 macOS 体验
- 隐私数据被收集
- 大文件编辑卡顿
- 配置复杂难以定制

## 设计理念
- 原生集成 macOS 外观与行为
- 轻量 4 MB 无臃肿
- 速度优先 流畅编辑千万行文件
- 严格遵循 GFM 规范
