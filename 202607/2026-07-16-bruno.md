## TL;DR
一个开源的 Git 原生 API 客户端，将集合存储为纯文本文件，本地运行，通过 Git 进行团队协作而不是依赖云同步

## 应用场景
- 作为 Postman 的开源替代品，进行 API 请求测试与调试
- 在开发团队中通过 Git 共享和版本控制 API 集合
- 将 API 集合与代码库共存，提升可发现性和一致性
- 在无网络或安全敏感环境中本地使用 API 客户端
- 通过现有 Git 权限和审计日志实现企业级 API 治理
- 与 VS Code 等 IDE 集成，在开发环境中直接管理 API 请求
- 用于 CI/CD 流程中的自动化 API 测试（结合 CLI）

## 用户痛点
- Postman 等工具要求创建账户并将数据同步到云端，导致隐私泄露风险
- API 集合无法与代码一样通过 Git 进行版本控制和代码审查
- 云同步的工具在离线时功能受限或无法使用
- 传统 API 客户端逐渐变成臃肿的平台，不再专注于开发者体验
- 企业需要额外配置 SSO、RBAC 等权限，增加管理复杂度
- API 集合存储在云端，不属于团队自己管理，数据不可控

## 设计理念
- Git 原生
- 本地优先
- 开发者优先
- 开源可扩展
