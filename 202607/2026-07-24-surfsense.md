## TL;DR
开源的 NotebookLM 替代品，为 AI agents 提供从 Reddit、YouTube 等社交平台抓取结构化实时数据的连接器，并内置研究工作空间与知识库

## 应用场景
- 使用 AI agent 从社交媒体平台收集用户评论进行趋势分析
- 监控 Google Maps 商家评价和业务信息用于市场调研
- 提取 YouTube 视频评论和字幕进行情感分析
- 从 TikTok 和 Instagram 抓取热门内容追踪流行趋势
- 通过 SERP API 跟踪关键词排名和 AI 概述变化
- 抓取 Amazon 产品价格和评论用于竞品分析
- 爬取任意网页内容并转换为 LLM 可读格式

## 用户痛点
- 官方社交平台 API 限制多、费用高、审核门槛高
- 从多个异构平台收集结构化数据需维护不同接口
- 手动收集网络公开数据效率低且难以规模化
- 非结构化网页内容转化为 AI 模型可用格式麻烦
- 需要实时监控网络动态但缺乏自动化工具
