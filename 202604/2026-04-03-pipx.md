## TL;DR
一个用于在隔离环境中安装和运行 Python 应用程序的工具，类似于 brew 但针对 Python 包

## 应用场景
- 安装 Python 命令行工具并避免依赖冲突
- 临时运行 Python 应用程序而不安装到系统
- 管理多个 Python 应用程序的独立环境
- 升级或卸载通过 pipx 安装的 Python 应用
- 在 CI/CD 流程中运行 Python 应用程序

## 用户痛点
- 直接使用 pip 安装 Python 应用可能导致系统 Python 环境混乱
- 不同 Python 应用间的依赖冲突难以解决
- 临时使用 Python 应用时不希望污染系统环境
- 难以管理多个 Python 应用程序的版本和依赖
- 需要 sudo 权限来安装全局 Python 包存在安全风险

## 设计理念
- 隔离环境
- 无依赖冲突
- 用户权限运行
- 简化安装流程
