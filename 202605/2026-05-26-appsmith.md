## TL;DR
一个开源低代码平台，用于构建管理面板、内部工具和仪表板，支持 25+ 种数据库和任何 API

## 应用场景
- 构建企业内部管理面板
- 创建数据可视化仪表板
- 开发 IT 自动化工具
- 构建客户 360 视图系统
- 创建服务管理工具

## 用户痛点
- 传统应用开发周期长，成本高
- 需要编程技能才能构建内部工具
- 难以快速连接多个数据源
- 定制化工具维护困难
- 缺乏灵活的 UI 组件库

## 设计理念
- 低代码开发
- 快速集成数据源
- 可扩展的组件架构
- 开源与社区驱动
