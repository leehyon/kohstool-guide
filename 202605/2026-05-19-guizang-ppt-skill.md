## TL;DR
一个适配 Claude Code 等 Agent 环境的网页 PPT 技能，用于生成单文件 HTML 横向翻页 PPT、配图和多平台封面

## 应用场景
- 将长文章转换为演讲 PPT
- 生成瑞士风或电子杂志风格的幻灯片
- 为不同平台创建统一视觉风格的封面
- 重新设计产品截图以匹配 PPT 风格
- 基于文章或文档创建专业演示文稿

## 用户痛点
- 传统 PPT 制作耗时且设计门槛高
- 难以保持跨平台视觉一致性
- AI 生成的内容缺乏专业设计美感
- 多人协作编辑静态 HTML 文件困难
- 大段表格数据在 PPT 中展示效果不佳

## 设计理念
- 结构优于装饰
- 图片是第一公民
- 低性能可退场
- 瑞士风必须守版式
