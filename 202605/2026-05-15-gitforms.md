## TL;DR
一个零成本的表单解决方案，使用 GitHub Issues 作为数据库，无需月费

## 应用场景
- 为网站着陆页添加联系表单
- 收集销售线索和客户反馈
- 创建多语言表单而不需要额外费用
- 在小项目中替代付费表单服务
- 自定义表单样式和文本内容

## 用户痛点
- 使用传统表单工具需要支付月费
- 需要外部数据库来存储表单数据
- 难以自定义表单外观和文本
- 担心垃圾邮件和数据安全
- 需要复杂的设置来部署表单

## 设计理念
- 零成本架构
- 配置驱动设计
- GitHub 作为数据存储
- 无需代码的自定义能力
