## TL;DR
以 Markdown 编写邮件并生成可定制 HTML 模板的开源工具，内置多种常用场景模板，提供可视化 Builder 与 AI 辅助能力

## 应用场景
- 快速生成密码重置、订单确认等事务性邮件模板
- 制作月度简报、产品公告、活动邀请等营销邮件
- 为新品发布和更新日志设计邮件通知
- 搭建欢迎邮件与用户引导系列邮件
- 生成发票、账单和月度报告邮件
- 制作购物车放弃挽回邮件
- 通过 Builder 可视化编辑并定制开源模板

## 用户痛点
- 手写 HTML 邮件代码繁琐且容易出错
- 邮件模板在不同客户端中兼容性难以保证
- 重复设计常用邮件缺乏标准化模板
- 可视化编辑器与代码编辑难以结合
- 营销和事务性邮件模板难以快速复用
- 从零构建邮件布局耗时且维护成本高

## 设计理念
- Markdown 优先
- 模板开源可复用
- 可视化 Builder
- AI 集成
- 轻量定制
