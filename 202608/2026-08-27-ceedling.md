## TL;DR
面向 C 语言的构建与测试工具，基于 Unity 和 CMock，自动组织测试与发布构建，简化测试管理工作流

## 应用场景
- 编写和运行 C 单元测试
- 自动生成 mock 和 stub 代码
- 管理多模块项目的测试构建流程
- 集成到持续集成系统
- 配置交叉编译和模拟器测试
- 与 IDE 或文本编辑器配合使用
- 快速生成项目骨架与测试文件

## 用户痛点
- 手动编写测试 main 函数和测试运行列表
- 维护测试文件与源文件之间的关联关系
- 手工生成 mock 和 stub 容易出错且耗时
- 测试构建过程缺乏统一的命令行入口
- 不同工具链和平台的配置难以标准化
- 难以自动收集和汇总测试报告

## 设计理念
- 约定优于配置
- 自动化测试执行
- 单一配置文件
- 插件化扩展
