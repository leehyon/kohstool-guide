## TL;DR
开源跨平台 Linux 服务器管理桌面面板，通过本地 SSH 操作实现服务器零安装零残留，以轻量级原生客户端替代传统 Web 面板，降低安全风险

## 应用场景
- 通过 SSH 终端远程连接并管理 Linux VPS
- 使用 SFTP 进行远程文件上传、下载和批量操作
- 一键搭建和运维 LNMP 环境（Nginx、MySQL、PHP、Redis）
- 管理 Docker 容器、镜像和日志
- 创建配置网站、反向代理和 SSL 证书
- 管理数据库、用户权限及备份恢复
- 配置防火墙、BBR 和系统监控

## 用户痛点
- 传统 Web 面板需在服务器安装额外代码，占用资源并扩大攻击面
- 面板常开放 8888、8080 等端口，容易被扫描和入侵
- 面板自身以 root 权限运行，存在漏洞时可直接导致服务器失陷
- 卸载面板需登录服务器执行脚本，残留文件难以清理
- 同时管理多台服务器时，需频繁切换不同面板或登录页面

## 设计理念
- 本地优先，所有操作通过本地 SSH 完成
- 零服务器端安装，无额外端口暴露
- 安全优先，从根源消除面板自身风险
- 轻量级桌面应用，安装包仅 6 MB
- 多服务器并发管理和独立会话
