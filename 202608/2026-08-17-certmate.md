## TL;DR
自托管 TLS 证书管理系统，支持 29+ DNS 提供商自动签发与续期，具备可审计、防篡改的日志链，提供 Web UI、REST API、CLI 与 MCP 集成，密钥永不离场

## 应用场景
- 自动签发与续期 TLS 证书，避免服务因证书过期而中断
- 在 29+ 个 DNS 提供商之间统一管理多域名证书
- 通过 Web UI 或 REST API 集中监控证书状态与部署情况
- 使用 CLI 或 SDK 将证书操作集成到 CI/CD 流水线
- 通过 OIDC/SSO 与 RBAC 实现团队协作和细粒度权限控制
- 结合 MCP 服务器让 AI 代理辅助执行证书管理操作
- 生成合规所需的防篡改、可第三方验证的审计报告

## 用户痛点
- 证书手动续期易遗漏，导致服务意外中断
- 多域名、多云环境证书分散，难以集中管理
- 私钥与部署凭证在多系统间流转，存在安全风险
- 缺乏可验证的审计记录，难以满足合规要求
- 无法确认证书是否真正部署到目标服务，只知已签发

## 设计理念
- 自托管优先
- 防篡改审计链
- 密钥永不离场
- 自动化与可编程性
