## TL;DR
本地运行开源大语言模型的命令行工具，支持多种硬件与模型，无需 API Key 和网络连接，所有数据留在电脑上，强调隐私与自主权

## 应用场景
- 在本地电脑上运行大语言模型进行对话与问答
- 开发者本地测试和调试开源模型
- 处理敏感数据时离线使用 AI 功能
- 在没有网络的环境中启动本地推理服务
- 在异构硬件（苹果芯片、英伟达 GPU 等）上部署模型
- 配合本地编码代理自动发现并调用模型
- 通过命令行批量运行模型推理任务

## 用户痛点
- 依赖云 API 导致数据可能泄露
- 在线服务受网络状况影响且延迟较高
- 使用专有服务需要付费或申请 API Key
- 大模型数据与对话记录无法完全自主掌控
- 现有工具对多种硬件适配不足难以利用本地算力
- 离线环境缺少可用的大模型推理方案

## 设计理念
- 本地优先
- 开源开放
- 硬件自适应优化
- 隐私与数据所有权
