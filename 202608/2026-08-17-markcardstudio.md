## TL;DR
本地优先的 Markdown 社交媒体卡片排版与导出工具，支持智能分页、多平台尺寸、16 款内置主题、KaTeX 公式与 Mermaid 图表，可导出 PNG 或 PDF

## 应用场景
- 将 Markdown 文档一键生成社交媒体卡片
- 为小红书、抖音、微博等平台制作指定尺寸配图
- 将技术文章或笔记导出为多页 PDF
- 使用 KaTeX 公式与 Mermaid 图表渲染富内容
- 通过智能分页切分长文档为多张卡片
- 自定义主题与背景，产出风格统一的视觉内容
- 本地管理 Markdown 文件并恢复未保存草稿

## 用户痛点
- 手动排版社交媒体卡片费时费力
- 需要分别适配不同平台的图片尺寸
- 公式、图表难以在普通卡片工具中渲染
- 长文档难以自动分页并保持美观
- 在线工具存在隐私与数据安全问题

## 设计理念
- 本地优先
- Markdown 到卡片一站式流程
- 智能分页
- 多主题视觉风格
