## TL;DR
一款将 Markdown 文档转换为交互式思维导图的工具，支持实时预览和自定义样式

## 应用场景
- 将复杂文档结构可视化呈现
- 创建项目计划和知识图谱
- 整理会议记录和头脑风暴结果
- 制作教学材料和演示文稿
- 组织个人知识库和笔记

## 用户痛点
- 传统 Markdown 文档缺乏视觉层次结构，难以快速理解复杂内容
- 手动创建思维导图耗时且难以与 Markdown 内容同步
- 需要在不同格式间转换文档时信息容易丢失
- 大段文本内容难以直观展示其内部逻辑关系

## 设计理念
- Markdown 优先
- 实时可视化
- 轻量级交互
- 可扩展性
