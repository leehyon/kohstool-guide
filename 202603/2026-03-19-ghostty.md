## TL;DR
一个快速、功能丰富且跨平台的终端模拟器，使用平台原生 UI 和 GPU 加速

## 应用场景
- 开发人员在命令行界面高效编写和调试代码
- 系统管理员远程管理服务器和执行脚本
- 数据科学家运行命令行工具处理数据
- DevOps 工程师部署和监控云服务
- 终端用户享受流畅的文本渲染和交互体验

## 用户痛点
- 传统终端模拟器性能低下，渲染大量文本时卡顿
- 跨平台终端体验不一致，配置和快捷键不统一
- 终端字体渲染和缩放功能有限
- 缺乏现代化的 UI 和 GPU 加速支持
- 终端配置复杂，难以在不同环境间同步

## 设计理念
- 平台原生 UI 设计
- GPU 加速渲染
- 高性能终端模拟
- 简洁而强大的配置系统
