- Platform: Mac

## TL;DR
在 Mac 上运行多个编码代理工具，并行处理代码任务并自动管理 git 工作树

## 应用场景
- 并行处理多个代码仓库的开发任务
- 使用 AI 代理加速代码编写和调试
- 管理多个隔离的开发工作空间
- 审查和合并多个代理生成的代码变更
- 提升全栈开发效率

## 用户痛点
- 手动管理多个 git 工作树复杂且容易出错
- 同时运行多个 AI 编码代理缺乏统一管理平台
- 在多个项目间切换上下文效率低下
- 代码审查和合并多个代理的变更耗时
- 缺乏能够充分利用 AI 编码代理能力的工具

## 设计理念
- 并行工作流
- 隔离工作空间
- 自动 git 管理
- 集中式代码审查
