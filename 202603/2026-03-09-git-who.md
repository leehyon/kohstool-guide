## TL;DR
一个命令行工具用于分析代码库中各组件或子系统的贡献者信息

## 应用场景
- 分析大型代码库中各模块的主要贡献者
- 识别特定代码区域的维护责任人
- 跟踪项目历史中的活跃开发者
- 评估团队成员的贡献度
- 确定代码库中需要关注的部分
- 可视化项目的历史演变过程
- 识别需要文档或重构的代码区域

## 用户痛点
- 传统 git blame 只能追踪单行代码的作者，无法识别整个组件的贡献者
- 在大型项目中难以快速了解哪些开发者负责特定模块
- 无法直观地看到代码库中各部分的历史演变和责任归属
- 难以评估团队成员在特定时期或模块的贡献度
- 无法快速识别需要关注或维护的代码区域

## 设计理念
- 文件树级别的代码分析
- 多维度贡献指标展示
- 命令行工具的高效交互
- 灵活的过滤和排序选项
