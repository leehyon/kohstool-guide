## TL;DR
一个专为移动设备设计的 Web IDE，支持多种 AI 编码工具，提供文件管理、Git 集成和终端功能

## 应用场景
- 在移动设备上进行代码编辑
- 使用 AI 编码助手如 Claude Code 和 Gemini CLI
- 远程管理 Git 仓库
- 通过浏览器访问开发环境
- 跨平台进行轻量级开发工作

## 用户痛点
- 传统 IDE 在移动设备上使用不便
- 现有 AI 编码工具过于复杂臃肿
- 缺乏轻量级、专注核心功能的 Web IDE
- 需要随时随地进行代码编辑和 Git 操作
- AI 生成代码时需要适当监督和控制

## 设计理念
- 极简主义设计
- 移动优先
- 核心功能聚焦
- 用户完全控制
