## TL;DR
一个现代化的 Web 框架，专注于速度、可靠性和简单性，支持零运行时开销和岛屿式客户端水合

## 应用场景
- 构建高性能的现代化 Web 应用
- 创建具有交互性的静态网站
- 开发需要快速部署的全栈应用
- 使用 TypeScript 进行全栈开发
- 构建基于文件系统路由的应用

## 用户痛点
- 传统框架通常需要大量配置才能开始开发
- 许多框架默认发送大量 JavaScript 到客户端，影响加载速度
- 构建高性能应用时需要处理复杂的客户端水合逻辑
- 在保持开发体验的同时优化应用性能具有挑战性

## 设计理念
- 零运行时开销
- 岛屿式客户端水合
- 无配置必要
- 文件系统路由
