# Zed
- URL: https://zed.dev/
- Added: 2026-03-10 06:21:36
- Tags: Code Editor, AI Integration, Collaboration, Rust, Fast
- Categories: Text Input & Writing, Developer Tools, Communication
- Platform: Mac, Linux, Windows

## TL;DR
一款用 Rust 编写的高性能代码编辑器，支持 AI 协作与团队实时协作

## 应用场景
- 编写和编辑代码
- 与 AI 协作生成和转换代码
- 团队实时协作编辑
- 调试多语言程序
- 进行 Git 版本控制操作
- 远程开发项目

## 用户痛点
- 传统代码编辑器启动速度慢
- 编辑器响应延迟影响编码体验
- 缺乏与 AI 的无缝集成
- 团队协作功能有限
- 跨平台支持不足

## 设计理念
- 高性能优先
- AI 集成
- 实时协作
- 跨平台支持
