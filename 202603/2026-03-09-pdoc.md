## TL;DR
自动生成 Python 项目的 API 文档，无需配置，支持类型注解和交叉链接

## 应用场景
- 为 Python 库生成完整的 API 文档
- 实时预览文档更改的 Web 服务器
- 支持 numpydoc 和 Google 风格的文档字符串
- 自动处理项目模块层次结构
- 为开源项目提供标准化的文档格式

## 用户痛点
- 手动编写和维护 API 文档耗时且容易出错
- 传统文档工具配置复杂，学习成本高
- 文档与代码不同步导致信息过时
- 难以在文档中展示类型信息和交叉引用
- 缺乏便捷的实时预览机制

## 设计理念
- 零配置
- 自动类型注解支持
- 模块层次结构保留
- 实时预览
