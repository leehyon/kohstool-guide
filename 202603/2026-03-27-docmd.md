## TL;DR
一个极简快速的文档生成工具，从 Markdown 创建美观文档，无 React 冗余，专为开发者设计

## 应用场景
- 为开源项目创建技术文档
- 构建产品 API 文档
- 团队内部知识库文档
- 个人博客或作品集展示
- 多版本文档管理与发布

## 用户痛点
- 传统文档工具配置复杂，学习成本高
- 生成文档体积大，加载速度慢
- 缺乏多版本管理功能
- 文档搜索功能依赖第三方服务
- 离线环境下无法访问文档内容

## 设计理念
- 零配置启动
- 纯静态输出
- 轻量级架构
- 开发者友好
