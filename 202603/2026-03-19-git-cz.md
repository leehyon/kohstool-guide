## TL;DR
一个轻量级的 Git 提交信息生成工具，支持语义化提交和自定义配置

## 应用场景
- 规范化 Git 提交信息格式
- 支持团队协作中的统一提交规范
- 生成符合 Conventional Commits 标准的提交信息
- 支持非交互式提交信息生成
- 自定义提交消息格式和类型
- 集成到 CI/CD 流程中

## 用户痛点
- 手动编写 Git 提交信息不规范且不一致
- 难以追踪代码变更的类型和范围
- 生成变更日志时难以从提交信息中提取有效信息
- 团队成员提交信息格式不统一导致混乱
- 难以快速识别破坏性变更

## 设计理念
- 轻量级设计
- 交互式提示
- 可配置格式
- 语义化提交
