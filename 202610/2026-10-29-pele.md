## TL;DR
将 Mermaid 语法快速渲染为可主题化 SVG 的轻量库，零依赖、体积小、渲染快，支持 Mermaid 全部图表类型

## 应用场景
- 在 Obsidian 笔记中快速渲染流程图与架构图
- 在 Web 应用中嵌入可主题化的 SVG 图表
- 为文档、博客或知识库生成轻量图表
- 使用 CSS 变量统一图表配色与字体风格
- 在移动端小屏幕上自适应展示复杂图表
- 评估或迁移 Mermaid 图表渲染方案

## 用户痛点
- Mermaid.js 体积大、依赖多，拖慢页面加载
- 图表渲染速度慢，复杂图或长文档中容易卡顿
- 图表主题与页面样式难统一，改色常需重新渲染
- 小屏幕直接缩放图表导致文字过小难读
- 在笔记软件中图表加载慢且样式不协调
- 自行实现图表渲染器成本高、兼容性难保证

## 设计理念
- 零依赖轻量
- CSS 变量主题化
- 小屏自适应布局
- 兼容 Mermaid 语法
