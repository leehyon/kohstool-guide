## TL;DR
七款用 Rust 从零编写的开源创意应用，覆盖图像、矢量、视频、照片、PDF、动效与排版，原生运行、免费使用，也能在浏览器里跑

## 应用场景
- 替代 Photoshop 做开源图像编辑与修图
- 用纯 Rust 工具做矢量插画与图标设计
- 剪辑视频并制作动效与视觉特效
- 管理本地照片库并处理 RAW 文件
- 读取、合并、拆分与加密 PDF 文档
- 做页面排版与出版物设计
- 通过 CLI 或 MCP 让 AI Agent 自动批量处理素材

## 用户痛点
- 专业创意软件订阅费用高，个人和小团队负担重
- 剪辑、绘图、排版分散在不同软件里，格式与流程割裂
- Electron 套壳应用体积大、启动慢、占用内存高
- 创意工作依赖云端上传下载，隐私与网速都受限
- 自动化程度低，批量处理只能靠手工重复操作
- 老牌开源工具界面陈旧，快捷键与工作流需要重新学习

## 设计理念
- 开源可审计，全部代码在 GitHub 上以宽松许可发布
- 原生而非套壳，纯 Rust 编译为真正的桌面应用
- 沿用专业用户熟悉的布局、工具与快捷键，零学习成本
- 本地优先，文件与算力都在用户自己的机器上
- Agent 友好，提供 CLI、JSON 控制通道与 MCP 服务
- 一套代码同时编译到桌面端与 WebAssembly 浏览器端
