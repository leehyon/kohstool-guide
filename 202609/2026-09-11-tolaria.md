## TL;DR
面向 AI 时代的开源第二大脑，将笔记存为 Markdown 文件，内置原生关系、Git 版本控制、本地 AI 代理与直接模型连接，免费且无需账号

## 应用场景
- 用 Markdown 文件管理成千上万条个人笔记与知识库
- 在笔记中建立双向链接与原生关系，构建知识网络
- 借助内置 Git 客户端对笔记进行版本控制与多设备同步
- 调用本地 CLI 编码代理或 API 模型，基于笔记上下文进行 AI 对话与编辑
- 用块编辑器与斜杠命令快速记录、整理和检索信息
- 编写技术文章时从大量笔记中组织素材与引用
- 将笔记库作为 Git 仓库进行协作与历史追溯

## 用户痛点
- 笔记软件使用私有格式与数据库，难以迁移和长期保存
- 知识散落在多个应用，缺少原生关联与可视化关系
- 无法直接对笔记进行版本控制，误删或改错难以恢复
- AI 助手与笔记库割裂，无法基于个人上下文高效工作
- 需要额外配置插件才能实现 Git 同步与 Markdown 编辑
- 商业笔记工具收费且强制账号登录，数据不在自己手中

## 设计理念
- 纯 Markdown 与本地文件优先
- Git 优先的版本控制
- 双向链接与关系为一等公民
- AI 代理与直接模型深度集成
- 块编辑器与源码格式兼容
