## TL;DR
基于 Vite 与 Vue 的静态站点生成器，用 Markdown 快速创建美观文档站，开发热更新快，构建后加载迅速

## 应用场景
- 为开源项目快速搭建美观的文档站点
- 将 Markdown 笔记整理为可部署的静态网站
- 编写产品手册、API 文档与帮助中心
- 搭建个人技术博客或知识库
- 在 Markdown 中嵌入 Vue 组件做交互式文档
- 使用热更新本地预览文档写作效果
- 生成加载快、SEO 友好的静态页面

## 用户痛点
- 手写 HTML/CSS 搭建文档站费时且难以维护
- 普通 Markdown 预览缺少导航、搜索与美观主题
- 传统文档生成器启动慢、热更新卡顿
- 想在文档中使用 Vue 组件但配置复杂
- 静态站点路由与首屏性能需要手动优化
- 多人协作时文档结构不统一、部署流程繁琐

## 设计理念
- Markdown 优先
- Vite 极速开发体验
- Vue 组件可扩展
- 静态生成与客户端路由结合
- 开箱即用默认主题
