## TL;DR
面向终端与 AI Agent 的 Z-Library 命令行客户端，支持书目搜索、文件下载、Kindle 邮件投递，能探测可用镜像，并提供 --json 输出供脚本和编码代理复用

## 应用场景
- 在终端中搜索 Z-Library 书目并浏览结果
- 按 ID 下载电子书并查看实时进度
- 将本地文件发送到 Kindle 邮箱
- 让 Claude Code 或 Codex 等 AI Agent 直接帮忙找书
- 在镜像站不稳定时探测可用的 Z-Library 域名
- 用脚本批量查询和下载，解析 JSON 输出
- 查看今日下载额度及重新下载历史记录

## 用户痛点
- Z-Library 网页域名常被 DiamWall 拦截，手动寻找可用镜像很耗时
- 登录状态和可用域名容易失效，需要反复试错
- 下载书籍和发送 Kindle 要切换多个网页操作，打断终端工作流
- 镜像站返回 JS 工作量证明或重定向时，普通用户难以处理
- 在脚本或 AI Agent 中调用缺少结构化、可解析的命令行输出

## 设计理念
- 终端优先，不离开命令行完成搜书和下载
- 子命令全部可脚本化并支持 JSON 输出
- 先探测镜像可用性，再处理验证码和重定向
- 人与 AI Agent 共享同一个二进制与输出格式
- 单一 Go 模块，预编译二进制跨平台免复杂依赖
