## TL;DR
用 Markdown 编写文档，几分钟内生成可搜索、可定制的专业静态网站，支持 60+ 语言与多设备

## 应用场景
- 为开源项目搭建专业的产品文档站点
- 为 API、SDK 编写可搜索的技术手册
- 为团队构建基于 Markdown 的内部知识库
- 快速生成支持多语言和多设备的文档网站
- 制作带社交卡片预览的文档或博客
- 构建可离线搜索的静态文档

## 用户痛点
- 从零手写 HTML、CSS 和 JavaScript 搭建文档站点耗时且门槛高
- 第三方文档平台更新慢、搜索依赖爬虫且难以定制
- 文档在桌面、平板和手机上显示效果不一致
- 难以在代码块旁添加图文并茂的注释和说明
- 将文档托管到第三方平台会削弱对内容源和数据的控制
- 缺少图标、表情和视觉元素，技术写作表达单调

## 设计理念
- Markdown 优先，专注内容
- 配置化定制，无需前端经验
- 内置快速搜索与离线支持
- 响应式适配全设备，开源且数据自主
